# Personal Book Recommender

A Python-based book recommendation system that suggests books based on users' reading preferences and personal ratings.

## Objective

The goal of this project is to develop a personalized recommendation system using information from a user's book collection.

Users can select their preferred genre and desired book length to receive recommendations from their unread books.

## Features

- Reading data from Excel spreadsheets
- Exploratory Data Analysis (EDA)
- Analysis of reading preferences and personal ratings
- Genre-based book recommendations
- Book length filtering (short, medium, and long)
- Personalized recommendation ranking

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Methodology

The initial recommendation system uses users' historical ratings to estimate genre preferences.

Books are ranked according to their genre compatibility, with optional filters based on the user's current reading preferences.

Future improvements may include content-based filtering and cosine similarity.

## Dataset

The project uses a personal book collection stored in an Excel spreadsheet.

For privacy reasons, the original dataset is not publicly available. Users can provide their own spreadsheet following the expected data structure.
